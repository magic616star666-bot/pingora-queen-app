# Pingora: Your Connection Hub

Build a polished mobile-first full-stack messaging app called Pingora, inspired by the feature depth and ease of use of modern messaging apps like WhatsApp but with completely original branding, colors, icons, layout details, and visual identity. Make it feel like a real consumer app, not a demo. Start with a strong working foundation: onboarding, sign-in/sign-up flow, editable user profile with photo/name/about, chat list, one-to-one chat screen, real-time-feeling message interactions, sent/delivered/read states, timestamps, reply, reactions, edit/delete/copy/forward UI, emoji, attachment sheet, photo/video/document/voice-note UI, search, pinned/archived/muted chats, typing/online/last-seen states, dark mode, responsive mobile keyboard/safe-area behavior, and installable PWA support. Include tabs for Chats, Updates/Status, Communities, and Calls; group chat creation and group info screens; 24-hour status/story UI; call history and voice/video calling screens; settings for privacy, notifications, chats, storage/data, linked devices, blocked users, and profile. Use realistic sample data only where needed so every screen can be explored immediately. Build clean reusable TypeScript components with Tailwind/shadcn and make navigation and interactions functional. Prepare the architecture for a real cloud database, authentication, media storage, realtime messaging, push notifications, and later Android packaging. Do not copy WhatsApp trademarks, logo, or exact UI. Prioritize an excellent Android-phone experience and original Pingora branding.
